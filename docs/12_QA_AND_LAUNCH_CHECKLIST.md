# QA & Launch Checklist

## Content
- [ ] Business name verified.
- [ ] Address verified.
- [ ] Hours verified.
- [ ] Phone/WhatsApp verified.
- [ ] Menu and prices verified.
- [ ] Social links verified.
- [ ] No TBD/placeholder content remains in production.
- [ ] No unsupported claims.

## UX
- [ ] Navigation works.
- [ ] Menu is readable on mobile.
- [ ] Contact CTA works.
- [ ] Location CTA works.
- [ ] Images have useful alt text.
- [ ] Focus states visible.
- [ ] Buttons have adequate tap areas.

## Technical
- [ ] Build passes.
- [ ] No console errors.
- [ ] No broken links.
- [ ] Responsive layout checked.
- [ ] Metadata checked.
- [ ] Sitemap/robots checked when applicable.
- [ ] Images optimized.
- [ ] Secrets absent.

## Launch
- [ ] Production URL verified.
- [ ] HTTPS verified.
- [ ] Social preview verified.
- [ ] Mobile production smoke test completed.
- [ ] Business owner review completed.
