# UI/UX Direction

## Principles
- Mobile-first.
- Fast first render.
- Clear hierarchy.
- Large tap targets.
- High text contrast.
- Minimal navigation.
- Real photography over stock imagery.
- Persistent but non-intrusive contact CTA on mobile.

## Components
Header/navigation, hero, CTA buttons, menu cards, gallery, business-info cards, location block, FAQ when useful, footer.

## Accessibility
Use semantic HTML, keyboard navigation, visible focus states, meaningful alt text, labeled controls and reduced-motion support.

## Constraint
The visual system should feel like Sinau Kopi, not a generic coffee template.
